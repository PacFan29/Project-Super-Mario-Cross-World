【プロンプト】
以下のキャラクターの待機アニメーション（何も操作しないまましばらく経つと実行されるアニメーション）を提案してみて。
・マリオ（スーパーマリオ）
・ルイージ（スーパーマリオ）
・ピーチ姫（スーパーマリオ）
・ヨッシー（スーパーマリオ）
・ロゼッタ（スーパーマリオ）
・パックマン（パックマン）
・ミズ・パックマン（パックマン）
・パック・ジュニア（パックマン）
・ロックマン（ロックマン）
・ロール（ロックマン）
・ブルース（ロックマン）
・フォルテ（ロックマン）
※チームソニックは過去作オマージュ。

【回答】
いいね。待機アニメーションなら、\*\*「そのキャラらしさが一目で分かる」「短くてもループできる」「操作していないことが伝わる」\*\*の3点を軸にすると映えそうです。

 キャラクターごとに、ゲーム内で実装しやすいように「基本の待機 → 少し長く放置した場合の追加演出」というイメージで提案します。

 ## スーパーマリオ系

 ### 🍄 マリオ

 - **基本待機**：その場で軽く足踏みしながら、周囲をキョロキョロ。「暇だな」という感じで肩をすくめる。
- **長時間待機**：帽子を直し、カメラの方を見て「Let's go!」と小さくガッツポーズ……するものの、誰も操作してくれないので「あれ？」と首をかしげる。
- **ポイント**：元気いっぱいだけど、ちょっとコミカル。

 ### 🟢 ルイージ

 - **基本待機**：落ち着かず、左右を何度も確認。マリオがいないか探しているような仕草。
- **長時間待機**：背後から何かを感じたようにビクッ！ → 恐る恐る振り返る → 何もいなくてホッとする。
- **さらに長時間**：安心して深呼吸した瞬間、また何かを感じて飛び上がる。
- **ポイント**：臆病さを活かしたコミカルなループ。

 ### 👑 ピーチ姫

 - **基本待機**：スカートを軽く整え、髪を触りながら優雅に周囲を見渡す。
- **長時間待機**：小さくあくび → 「あら、まだかしら？」という表情 → 退屈そうに頬杖。
- **さらに長時間**：暇つぶしに小さな花を出して眺め、嬉しそうに微笑む。
- **ポイント**：上品さを崩さず、「待たされている感」を可愛く表現。

 ### 🦖 ヨッシー

 - **基本待機**：尻尾を左右に振りながら、キョロキョロ。
- **長時間待機**：地面に落ちている何かを発見 → 舌を伸ばしてペロッと取る → 食べて嬉しそうにする。
- **さらに長時間**：お腹が空いたのか、周囲を探し始める。
- **ポイント**：舌・食欲・尻尾など、ヨッシー特有の身体表現をふんだんに使う。

 ### 🌌 ロゼッタ

 - **基本待機**：ゆっくり浮遊するように体を揺らし、髪やドレスがふわっと動く。
- **長時間待機**：手をかざすと小さな星が現れ、それを眺める。
- **さらに長時間**：星を指で軽く弾くと、星が周囲を一周して戻ってくる。ロゼッタが微笑む。
- **ポイント**：激しい動きではなく、\*\*「静かな宇宙」「神秘的な時間」\*\*を感じさせる。

 # パックマン系

 ### 🟡 パックマン

 - **基本待機**：左右をキョロキョロしながら、口をパクパク。
- **長時間待機**：何かを発見したように目を輝かせる → ゴーストを追いかけようとする → しかし画面端まで行ったところで「あ、操作されてない」と気づいて戻ってくる。
- **別案**：目の前に小さなペレットが出現 → 食べる → もう一個出現 → 食べる……と夢中になる。
- **ポイント**：**「パクパク」という単純な動きをアイコン化**すると非常にパックマンらしい。
（参照：パックマンワールド リ・パック）

 ### 💗 ミズ・パックマン

 - **基本待機**：髪飾りを整えたり、軽く身だしなみをチェック。
- **長時間待機**：小さな鏡を取り出して自分をチェック → 満足げに微笑む。
- **さらに長時間**：鏡をしまった直後、また気になってもう一度確認。
- **ポイント**：パックマンよりも仕草に女性らしさを加えつつ、コミカルに。

 ### 🟠 パック・ジュニア

 - **基本待機**：落ち着きなくぴょんぴょん跳ねる。
- **長時間待機**：ペレットを見つけて追いかける → 口を開けて食べようとする → 直前でペレットが逃げる → ムッとする。
- **さらに長時間**：今度こそ食べて大喜び。
- **ポイント**：子供らしい「じっとしていられない」感じ。

 # ロックマン系

 ### 🔵 ロックマン

 - **基本待機**：軽く腕を振りながら、戦闘態勢を保つ。
- **長時間待機**：周囲を警戒 → 何も起こらない → バスターを下ろす → 少しホッとする。
- **さらに長時間**：バスターを銃のように構え、射撃練習を数発 → 「よし」と頷く。
- **ポイント**：**戦闘用ロボットなのに待機中は少し普通の少年っぽい**、というギャップ。

 ### 🌸 ロール

 - **基本待機**：両手を後ろで組み、体を左右に揺らす。
- **長時間待機**：周囲を見回す → 掃除道具を取り出す → その場をちょこちょこ掃除。
- **さらに長時間**：掃除が終わると満足そうに頷く。しかしすぐに小さなゴミを発見して「あっ」となる。
- **ポイント**：ロールの「家事・お手伝いロボット」という個性をそのまま待機モーションに。

 ### ⚡ ブルース

 - **基本待機**：腕を組み、無言で立つ。時々マントが風で揺れる。
- **長時間待機**：目を閉じる → 静かに精神統一 → ふっと目を開ける。
- **さらに長時間**：背を向けて歩き出す……と思わせて、数歩進んだところで振り返る。
- **ポイント**：他キャラより動きを抑えて、**「孤高の戦士」感**を出す。

 ### 🖤 フォルテ

 - **基本待機**：腕を組み、露骨に不機嫌そうにこちらを見る。
- **長時間待機**：イライラしたように足を鳴らす → 「まだか？」という顔。
- **さらに長時間**：待ちきれず勝手にチャージ → 強烈な一撃を空中に放つ → 何事もなかったように腕を組み直す。
- **ポイント**：12人の中でも特に\*\*「放置されること自体を嫌がる」\*\*キャラにすると面白い。

 ## キャラ同士の差別化をさらに強くするなら

 12人を並べたときに、待機モーションだけで性格が分かるようにするとかなり良いと思います。

 | キャラ | 待機時のキーワード |
| --- | --- |
| マリオ | 元気・退屈・コミカル |
| ルイージ | 不安・警戒・ビクビク |
| ピーチ | 優雅・退屈・可憐 |
| ヨッシー | 好奇心・食欲・無邪気 |
| ロゼッタ | 静寂・星・神秘 |
| パックマン | 食欲・パクパク・遊び |
| ミズ・パックマン | 身だしなみ・優雅・お茶目 |
| パック・ジュニア | やんちゃ・好奇心・落ち着きなし |
| ロックマン | 真面目・訓練・少年らしさ |
| ロール | 家事・お手伝い・几帳面 |
| ブルース | 孤高・静寂・精神統一 |
| フォルテ | 不機嫌・挑発・戦闘欲 |

特に面白いのは、\*\*「放置時間が長くなるほど、そのキャラの本性が出る」\*\*という設計です。

 例えば、

 **0〜5秒：** ごく普通の呼吸・揺れ\
 ↓\
 **5〜15秒：** キャラ固有の小さな仕草\
 ↓\
 **15〜30秒：** 性格が出るコミカルな行動\
 ↓\
 **30秒以上：** 特殊な小ネタ・メタ的な演出

 という4段階にすると、待機アニメーションを見るためにあえて操作を止めたくなるゲームになりそうです。
